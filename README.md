# Premium Automotive Filtration Landing Page

A premium, modern, and high-performance landing page for an automotive filtration company (ZEYAD GROUP). The project features a sleek dark-themed design with elegant glassmorphism elements, dynamic hover states, and seamless multilingual support.

## 🚀 Features

- **Modern & Premium Design**: Dark theme, cinematic layout, and elegant glassmorphism UI.
- **Multilingual Support**: Fully supports Arabic (RTL) and English (LTR) with a seamless toggle.
- **High Performance**: Vanilla CSS and JS with hardware-accelerated animations for a solid 60fps experience.
- **Responsive Layout**: Perfectly optimized for all devices (Desktops, Tablets, and Mobile phones).
- **Interactive UI**: Custom Intersection Observer animations, count-up numbers, and premium hover effects.

## 🛠️ Tech Stack

- **HTML5**
- **Vanilla CSS3**
- **Vanilla JavaScript**
- **Vite** (for fast development and bundling)

## 📦 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   cd your-repo-name
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
